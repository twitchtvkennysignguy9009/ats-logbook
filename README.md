# Kenny's Truck Logbook

The public log of every load hauled in American Truck Simulator on
[twitch.tv/twitchtvkennysignguy9009](https://twitch.tv/twitchtvkennysignguy9009).

**Live page:** https://twitchtvkennysignguy9009.github.io/ats-logbook/

Each trip records where it started and where it ended, the load, the miles, the pay, the
damage to the truck and trailer, every fill-up, how many nights were slept on the road,
and every ticket the cops wrote — plus the real-world clock times the trip started and
finished.

This repo is generated. Nothing in it is edited by hand: the tracker at
`F:\talkshow-podcast\ats-violations` writes `data/runs.json` and pushes it when the
**Publish the logbook** button on the control page is clicked, or when
`Publish_Logbook.bat` is run.
